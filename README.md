# Newton Mitro - Attorney Portfolio

A responsive attorney portfolio website built as a lightweight static page with HTML and Tailwind CSS.

## Overview

The site presents Newton Mitro as an attorney at law based in Dhaka, Bangladesh, with a focus on:

- Corporate and commercial counsel
- Dispute resolution
- Property and succession matters
- Clear, practical client communication

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static web server.

## Project structure


## Customization

Update the contact details, location, practice areas, and representative matters in `index.html` before publishing.
