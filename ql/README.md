# Quantum Labs Website UI

Static multi-page Tailwind CSS website concept for QuantumLabs.tech.

## Pages
- index.html — Home
- services.html — Services
- solutions.html — AI & business solutions
- industries.html — Industries
- work.html — Case studies / portfolio
- about.html — About
- insights.html — Insights
- contact.html — Project inquiry

## Run
Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Styling
Tailwind CSS is loaded through the CDN, so an internet connection is needed for Tailwind to render in a browser.

## Notes
This is a UI prototype. The contact form is demo-only and does not send email.
